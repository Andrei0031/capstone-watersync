# Fix: Can't Click "Set" Button

## Problem: "Set" button is disabled after creating folder

## Solution:

### Step 1: Navigate INTO the Folder

1. **After creating the folder** `watermeter-ground-truth`:
   - **Double-click** the folder to open it
   - Or select the folder and press Enter

2. **The folder should now be empty** (that's OK for now)

3. **Click "Set" button** - it should work now!

---

## Alternative: Select the Folder (Not Open It)

If double-clicking doesn't work:

1. **Click once** on the `watermeter-ground-truth` folder to select it
2. **Make sure it's highlighted**
3. **Click "Set"** button

---

## If Still Not Working:

### Option 1: Put Some Files in the Folder First

1. **Close the dialog**
2. **Copy at least one image** to: `C:\xampp\htdocs\CAPSTONE\tesseract_training\watermeter-ground-truth\`
3. **Open the dialog again**
4. **Navigate to the folder**
5. **Click "Set"**

### Option 2: Use Parent Folder

1. **Navigate to:** `C:\xampp\htdocs\CAPSTONE\tesseract_training\`
2. **Select this folder** (parent folder)
3. **Click "Set"**
4. **jTessBoxEditor will use this as base**, you can specify subfolder later

### Option 3: Type Path Manually

1. **In the "File name:" field** at the bottom
2. **Type:** `C:\xampp\htdocs\CAPSTONE\tesseract_training\watermeter-ground-truth`
3. **Press Enter** or click "Set"
