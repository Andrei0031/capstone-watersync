# ⚡ Quick Start: Connect GitHub to Verpex (5 Minutes)

## Your GitHub URL
```
https://github.com/Andrei0031/capstone-watersync.git
```

---

## 3 Simple Steps

### 1️⃣ Open Verpex cPanel
- Log in → Find **"Git Version Control"** → Click **"Create"**

### 2️⃣ Clone Repository
- Select **"Clone a Repository"**
- Paste URL: `https://github.com/Andrei0031/capstone-watersync.git`
- Path: `public_html/`
- Click **"Create"**

### 3️⃣ Update Database
- File Manager → Edit `db.php`
- Replace with Verpex database credentials
- Save

---

## Done! ✅

Your site should now be live at: `https://yourdomain.com`
